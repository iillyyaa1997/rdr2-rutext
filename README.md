# Red Dead Redemption 2 mods

Small ASI plugins for RDR2 Story Mode (game 1.0.1491.50, ScriptHookRDR2 V2). Each mod lives in its own folder with its source, build script and README. Ready-made files are on the [Releases](https://github.com/iillyyaa1997/rdr2-mods/releases) page, tagged `<mod>-v<version>`.

| Mod | What it does |
|---|---|
| [RuText](rutext/) | Translates the hard-coded English text of ScriptHook mods from plain-text dictionaries; hideout memory for Bandit Hideouts |

## Build

Every mod has a `build.sh` that cross-compiles its `.asi` with mingw-w64 in a throwaway Docker container.
